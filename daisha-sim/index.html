一度押した台車は、そのあとどう動く？

道具の準備から、実験、テープの処理、グラフづくりまで、上から順に進む実験ナビ。終わったものはチェックして、次へ進もう。

０この実験で調べること

一度だけ押した台車は、手をはなしたあと、どんな運動をするのだろうか。

押す強さだけを変えて、2本のテープをくらべる。

弱く押し出すテープに「弱く」と書く
強く押し出すテープに「強く」と書く

１準備する

準備 0 / 0

班で分担して集めよう。そろったものからタップしてチェック。

    ２実験する

    上から順に。終わった手順はチェックして、次へ進もう。

      ３テープを処理する

      テープを6打点ごとに切って、並べて、測る

      弱く・強くの2本とも、この順番で処理する。「▶ 通して再生」で通して、ステップのボタンで1つずつ確認できる。

        STEP 0 / 8

        ※ アニメーションの点の位置や長さは説明用の例（西日本・60Hzなので6打点＝0.1秒）。

        ４測定値を入力する

        区間ごとの長さ（cm）

        ワークシートに書いた数字を、そのまま入力しよう。テープの区間が多い／少ないときは、下のボタンで区間を増減できる。数字は今、サンプル値が入っている——自分の班の記録に書きかえよう。

        ５グラフにする

        区間ごとの移動距離（0.1秒ごと）

        弱く押したとき 強く押したとき
